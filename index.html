Semester 2 Software Engineering Project

NEWSIFY was developed by Ahmad Ali and his team during their second semester at the National University of Sciences and Technology (NUST), School of Electrical Engineering and Computer Science (SEECS). The project integrates Google Gemini AI, NewsAPI, and a custom-built web interface to deliver real-time news intelligence. What started as a Java desktop application evolved into a full-stack web platform — demonstrating skills in API integration, prompt engineering, UI design, and cloud deployment.
